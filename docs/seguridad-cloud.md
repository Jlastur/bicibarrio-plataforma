# Decisión Cloud - BiciBarrio
- **Componentes:** Frontend en Vercel/Cloudflare Pages, API Serverless (Render/Railway), Base de datos PostgreSQL gestionada (Supabase/Neon), Pagos con Stripe.
- **Región y Disponibilidad:** Región UE (Madrid/Fráncfort) para cumplimiento RGPD. Multi-AZ. RTO < 15 min, RPO < 5 min.
- **Costes:** Capa gratuita estimada en 0,00 €/mes con umbrales de alerta al 50% y 80% de un presupuesto de emergencia de 15 €.
- **Plan de Salida:** Contenedores Docker y PostgreSQL estándar para evitar vendor lock-in.
