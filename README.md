# BiciBarrio - Plataforma

Proyecto BiciBarrio - Bootcamp DevOps Neoland.

## Propósito

Este repositorio contiene la documentación técnica y el trabajo colaborativo de la plataforma BiciBarrio, desarrollado durante el módulo DevOps de Neoland.

Incluye los objetivos de nivel de servicio (SLO) del sistema de reservas, la decisión de arquitectura cloud y las prácticas de colaboración mediante GitHub.

## Cómo contribuir

1. Crear una incidencia (Issue) en GitHub describiendo la tarea o mejora.
2. Crear una rama nueva a partir de `main`.
3. Realizar los cambios y registrarlos mediante commits siguiendo Conventional Commits.
4. Publicar la rama en GitHub.
5. Abrir una Pull Request (PR) relacionada con la incidencia.
6. Solicitar una revisión antes de fusionar los cambios con `main`.

## Documentación

- `docs/slo-reservas.md`: objetivos de nivel de servicio del sistema de reservas.
- `docs/decision-cloud.md`: decisión de arquitectura cloud.
