# Guía de contribución a BiciBarrio

## Preparación

Antes de comenzar, actualiza la rama main y crea una
rama específica para la incidencia que vas a resolver.

## Flujo de trabajo

1. Seleccionar una incidencia de GitHub.
2. Crear una rama independiente desde main.
3. Realizar los cambios necesarios.
4. Registrar los cambios mediante commits.
5. Subir la rama a GitHub.
6. Abrir una Pull Request vinculada a la incidencia.
7. Solicitar la revisión de otro compañero.
8. Fusionar los cambios tras obtener su aprobación.

## Conventional Commits

Los mensajes deben seguir el formato:

tipo: descripción breve

Ejemplos:

- docs: añade documentación
- feat: incorpora una funcionalidad
- fix: corrige un error
- chore: actualiza configuración

## Revisión y seguridad

Las Pull Requests dirigidas a main necesitan al menos
una aprobación de otro integrante del equipo.

No se permite forzar cambios sobre main ni incorporar
contraseñas, tokens u otros secretos al repositorio.
